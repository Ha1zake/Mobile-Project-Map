# 🗺️ Mobile Project Map

Mobile Project Map — командный проект мобильного приложения для построения и анализа маршрутов на карте.

Проект объединяет работу с картой, графовой моделью маршрутов и несколькими алгоритмами поиска/оптимизации пути. Основная идея приложения — дать возможность строить маршрут между точками и сравнивать разные алгоритмические подходы к решению задачи навигации.

---

## 🚀 Возможности проекта

- построение маршрутов между точками на карте;
- представление карты в виде графа;
- поиск кратчайшего или оптимального маршрута;
- использование нескольких алгоритмов маршрутизации;
- сравнение классических и эвристических подходов;
- разделение логики приложения на модули;
- командная разработка с использованием Git/GitHub.

---

## 🧠 Реализованные алгоритмы

В проекте реализовано несколько алгоритмов поиска и оптимизации маршрута:

### A*
Алгоритм поиска кратчайшего пути с использованием эвристики.  
Подходит для эффективного построения маршрута между двумя точками.

### Genetic Algorithm
Генетический алгоритм оптимизации маршрута.  
Использует идеи отбора, скрещивания и мутаций для поиска хорошего решения среди множества вариантов.

### Ant Colony Optimization
Муравьиный алгоритм оптимизации.  
Моделирует поведение муравьиной колонии и механизм феромонов для поиска эффективного маршрута.

### K-Means
Алгоритм кластеризации точек.  
Может использоваться для группировки объектов на карте и предварительной обработки данных маршрута.

### Tree-based Algorithm
Алгоритм, основанный на древовидной структуре данных.  
Используется для организации маршрутов, связей между точками или построения вспомогательной структуры графа.

## 🧱 Архитектура проекта

Проект логически разделён на несколько частей:

```text
UI / Mobile Interface
        ↓
Map / Graph Model
        ↓
Algorithms Module
        ↓
Route Building Logic
```

### Основные модули

- **UI / Interface** — взаимодействие пользователя с приложением;
- **Map Model** — представление карты и точек маршрута;
- **Graph Model** — хранение вершин, рёбер и связей между точками;
- **Algorithms** — реализация алгоритмов поиска и оптимизации;
- **Route Service / Logic** — слой, который связывает карту, граф и алгоритмы.

Такое разделение позволяет независимо развивать интерфейс, алгоритмы и внутреннюю модель маршрутов.
